About

FINQUEST AI - An intelligent multi-session RAG (Retrieval-Augmented Generation) document assistant. You can create multiple sessions, upload documents, and ask questions about them.

  • Supports PDF, DOCX, TXT, and Markdown files
  • Uses FAISS for efficient vector search
  • Persists data across sessions with TinyDB
  • Automatic fallback to Groq LLM if API fails (fast & free!)
