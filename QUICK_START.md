# 🚀 **Quick Start Guide**

## **One-Click Installation**

### **Windows Users:**
1. **Backend**: Double-click `backend/start_windows.bat`
2. **Frontend**: Double-click `frontend/start_windows.bat`

### **macOS Users:**
1. **Backend**: Run `./backend/start_macos.sh`
2. **Frontend**: Run `./frontend/start_macos.sh`

### **Linux Users:**
1. **Backend**: Run `./backend/start_linux.sh`
2. **Frontend**: Run `./frontend/start_linux.sh`

## **What You Need:**

- **Python 3.9+** (for backend)
- **Node.js** (for frontend)
- **Internet connection** (for API keys)

## **Access Your App:**

- **Frontend**: http://localhost:4200
- **Backend**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs

## **Get API Keys (Optional):**

- **Google Gemini**: https://makersuite.google.com/app/apikey
- **OpenAI**: https://platform.openai.com/api-keys

*No API key? No problem! The system automatically uses local AI models.*
